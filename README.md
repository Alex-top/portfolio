## 📂 Мои проекты

### 1️⃣ Бот-напоминалка для ВКонтакте
📌 [Репозиторий](https://github.com/Alex-top/bot_reminder)

**Краткое описание:**  
Бот позволяет создавать напоминания через текстовые команды. Поддерживает различные форматы времени (`через 10 минут`, `в 15:30`, `завтра в 10:00`). Отправляет уведомления в указанное время.

**Технологии:** Python, VK API, SQLite, планировщик задач (threading), логирование.

**Что показывает:** Умение работать с временем, базами данных, фоновыми процессами.

---

### 2️⃣ Бот для записи к специалисту (VK)
📌 [Репозиторий](https://github.com/Alex-top/booking_bot)

**Краткое описание:**  
Интерактивный бот для записи на услуги. Пользователь выбирает услугу, мастера, дату и время из доступных слотов. Запись сохраняется в базу данных. Реализована отмена записи.

**Технологии:** Python, VK API, SQLite, инлайн-клавиатуры, callback-кнопки.

**Что показывает:** Работу с расписанием, сложные диалоги, управление состояниями пользователя.

---

### 3️⃣ Бот для сбора отзывов (VK) + интеграция с Яндекс.Диском
📌 [Репозиторий](https://github.com/Alex-top/review-bot)

**Краткое описание:**  
Бот собирает отзывы и оценки (1–5) от пользователей. Все отзывы сохраняются в CSV-файл и автоматически синхронизируются с Яндекс.Диском. Есть статистика и просмотр своих отзывов.

**Технологии:** Python, VK API, Яндекс.Диск API, CSV, dotenv.

**Что показывает:** Работу с облачными сервисами (Яндекс), обработку пользовательского ввода, работу с файлами.

### 4️⃣ E-Commerce Bot Core (мультиплатформенное ядро)
📌 [Репозиторий](https://github.com/Alex-top/E-Commerce-Bot-Core)

**Краткое описание:**  
Универсальное ядро для e-commerce ботов с поддержкой нескольких платформ (консоль, VK, Telegram). Включает каталог товаров, корзину, оформление заказов. Демонстрирует архитектурный подход «ядро + адаптеры».

**Технологии:** Python, VK API, Telegram API (код готов), SQLite.

**Что показывает:** Архитектурное мышление, умение создавать масштабируемые решения.
