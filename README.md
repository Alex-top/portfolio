# Портфолио разработчика ботов для бизнеса

👋 Привет! Я создаю ботов для ВКонтакте, которые помогают бизнесу:
- автоматизировать приём заказов,
- управлять записями клиентов,
- собирать отзывы и обратную связь,
- напоминать о важных событиях.

Все боты работают **прямо в ВКонтакте** — без установки приложений, без сайта, без лишних затрат.

---

## 💼 Мои готовые решения

### 🤖 Бот-запись к специалисту
**Что умеет:**
- Показывает список услуг и мастеров
- Позволяет выбрать удобную дату и время
- Автоматически проверяет занятые слоты
- Отправляет клиенту подтверждение записи
- Позволяет отменить запись одним нажатием

**Кому подойдёт:** салоны красоты, стоматологии, фитнес-клубы, частные специалисты (репетиторы, юристы, врачи).

📌 [Код и демо](https://github.com/Alex-top/booking_bot)

---

### 🤖 Бот-напоминалка
**Что умеет:**
- Создаёт напоминания по текстовой команде (`через 10 минут`, `завтра в 15:30`)
- Отправляет уведомления точно в назначенное время
- Хранит все напоминания до тех пор, пока не будут выполнены

**Кому подойдёт:** HR-отделы, логистические компании, event-менеджеры — все, кто работает с дедлайнами.

📌 [Код и демо](https://github.com/Alex-top/bot_reminder)

---

### 🤖 Бот для сбора отзывов
**Что умеет:**
- Собирает оценки (по 5-балльной шкале)
- Запрашивает и сохраняет текстовый отзыв
- Показывает статистику по отзывам
- Автоматически сохраняет все данные в **Яндекс.Документы** — никаких Excel-файлов вручную!

**Кому подойдёт:** магазины, рестораны, гостиницы, службы доставки.

📌 [Код и демо](https://github.com/Alex-top/review-bot)

---

### 🛒 Универсальное ядро для интернет-магазина
**Что умеет:**
- Каталог товаров с ценами и описанием
- Корзина (добавление, удаление, изменение количества)
- Оформление заказа (сбор адреса, телефона, ФИО)
- Может работать как в VK, так и в Telegram — ядро общее для всех платформ

**Кому подойдёт:** интернет-магазины, handmade-маркетплейсы, сервисные компании.

📌 [Код и демо](https://github.com/Alex-top/E-Commerce-Bot-Core)
